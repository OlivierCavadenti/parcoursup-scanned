# Règles de rédaction

1. Toute affirmation importante renvoie à une source du registre (`references([...])`).
2. Une source « à vérifier » n'est jamais l'unique fondement d'une affirmation.
3. Distinguer explicitement : fait établi (code, texte), règle citée, choix de conception,
   pratique locale, hypothèse, inconnu.
4. Les exemples sont fictifs et présentés comme tels ; aucun nom réel, aucune donnée réelle
   d'élève.
5. Trois niveaux de lecture (Découverte, Approfondissement, Technique) sur les pages
   explicatives.
6. Ne jamais présenter un indicateur statistique comme une probabilité individuelle.
7. Typographie française : espaces insécables dans les guillemets « … ».
